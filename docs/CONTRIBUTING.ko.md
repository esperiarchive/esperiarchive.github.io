# 아카이브 개선에 도움을 주세요

[English](../CONTRIBUTING.md) · [한국어](CONTRIBUTING.ko.md) · [日本語](CONTRIBUTING.ja.md) · [简体中文](CONTRIBUTING.zh-CN.md)

> **AI 번역:** 이 안내는 [영문 안내](../CONTRIBUTING.md)를 바탕으로 작성했습니다. 아래에 인용한 대사는 게임에서 수집한 한국어 문구입니다.

빠진 대사, 잘못 연결된 초상화, 게임과 다른 내용을 발견하셨나요? 스크린샷, 영상, 짧은 설명 모두 도움이 됩니다. **편한 언어로 한 가지만 알려 주셔도 괜찮아요.**

## 가지고 있는 자료를 보내 주세요

[리더 홈](https://esperiarchive.github.io/)의 **피드백 보내기** 또는 [GitHub 이슈](https://github.com/esperiarchive/esperiarchive.github.io/issues)를 이용해 주세요. 피드백 양식은 리더에서 선택한 언어로 표시됩니다.

스토리나 캐릭터 이름과 발견한 내용을 알려 주세요. 리더 링크, 스크린샷, 영상이 있다면 함께 보내 주세요. 긴 영상은 해당 장면의 시간을 적어 주시면 찾기 쉬워요.

**예전에 찍은 영상이나 일부만 확인한 제보도 환영합니다.** 퀘스트를 다시 플레이하거나 목록 전체를 확인하실 필요는 없어요.

## 어떤 부분을 확인하면 되나요?

[현재 확인이 필요한 내용](CURRENT_CHECKS.ko.md)은 다음 세 가지입니다.

- **대사 순서:** 어떤 목표가 표시될 때 대사가 나오는지, 다른 대사와의 순서는 어떤지.
- **공식 문구:** 누락되었거나 기계 번역으로 대신 표시되는 부분의 실제 게임 문구.
- **위치 확인이 필요한 NPC 대화:** “찍찍?” 같은 대사를 포함해 이미 리더에 넣어 둔 대화입니다. 기존 영상에 보인다면 위치를 확인하는 데 도움이 됩니다.

각 항목에 스토리 이름, 확인된 목표 이름, 찾아볼 대사를 적어 두었습니다. 기억나는 부분만 골라 주세요.

## 예시: 대사 순서

**스토리:** [불청객과 대칭의 미학](https://esperiarchive.github.io/#/base/side/10010261?lang=kr&mode=full) — 초기 스토리의 서브 스토리  
**목표:** 탈렌 찾기  
**확인할 대사:**

> 근처가 휑하네요.
>
> 탈렌 양의 모습이 보이지 않아요. 다른 곳에 있는 걸까요?

이 장면이 기억나신다면 어느 대사가 먼저 나왔는지, 당시 어떤 목표가 표시됐는지 알려 주세요. 영상이 없어도 짧게 설명해 주시면 도움이 됩니다.

## 그 밖의 수정 제안

문구를 고칠 때는 실제 게임에서 확인한 표현인지, 직접 번역한 표현인지 알려 주세요. 화면 표시 문제라면 가능할 때 기기와 읽기 모드도 적어 주세요.

문서와 코드 수정도 환영합니다. 아카이브에 관한 문제는 다른 저장소를 찾지 않고 여기로 보내셔도 됩니다.
