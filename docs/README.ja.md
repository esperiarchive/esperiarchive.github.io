The Esperia Archiveは、*AFK Journey*の物語、キャラクター、さまざまな記録を一か所にまとめています。

お気に入りの場面を読み返したり、別の選択肢をたどったり、見逃した手紙や会話を読んだりしてみてください。

## ストーリーリーダー

プロローグから始まるメインストーリーやサイドストーリー、キャラクター同士の会話を読むことができます。

- **インタラクティブ:** 物語の流れに沿って読み進め、返答を選びます。
- **全スクリプト:** 連続した台本として読みながら、会話の選択肢を切り替えられます。

話者のポートレート、ムービーの字幕、視点の切り替わりを示す区切りによって、各場面を追いやすくしています。対応する場面では、ストーリーイベントや視覚効果も表示されます。

![ダークテーマのストーリー画面。キャラクターのポートレートと会話の選択肢が表示されています。](images/story-reader.png)

**設定**でマーリンの名前、性別、外見プリセットを選べます。現在は基本の姿とシーズンごとの衣装を用意しています。適用前にプレビューを確認でき、後からいつでも変更できます。

## キャラクターアーカイブ

勢力別に英雄を眺めたり、名前で検索したりできます。プロフィールを開くと、キャラクターの物語、スキル、会話、収録されているボイスを確認できます。

![勢力別のキャラクター一覧。ポートレートとクラスアイコンが表示されています。](images/character-archive.png)

## 文書とメール

ゲーム内の文書、手紙、メール、アイテム説明を読むことができます。タイトルや本文で検索して、覚えのある記録を探したり、エスペリアの新たな一面を見つけたりしてみてください。

![ダークテーマのメールアーカイブに表示されたホーガンからの手紙。](images/documents-mail.jpg)

## 自分に合った読み方で

ダークテーマとライトテーマを選ぶほか、端末の設定に合わせることもできます。文字サイズを調整して、PCでもスマートフォンでも読みやすくできます。

選択した言語は、ストーリー、キャラクター、文書の各画面で共通して使われます。マーリンの設定も、対応する会話やポートレートに反映されます。

## 対応言語とコンテンツ

**English · 日本語 · 한국어 · 中文**

可能な限りゲームの公式ローカライズを使用しています。未翻訳の箇所には、保存済みの機械翻訳やAI翻訳を補う場合があり、小さな**機械翻訳**ラベルで区別しています。

テキストと音声の収録状況は、キャラクター、ストーリー、言語によって異なります。複数の言語で読めても、音声は一つの言語しか用意されていないコンテンツもあります。

一部の物語、翻訳、ポートレート、音声はまだ揃っていません。不足している資料の提供や、機械翻訳の修正案を歓迎します。ゲーム内の内容と照合できるよう、ストーリー名またはキャラクター名、言語を明記し、可能であればスクリーンショットや参考資料も添えてください。
